# 判断与修复边界

| 项目 | 可报告 | 不能推断 |
|---|---|---|
| A href | 实际相对/绝对地址、base、业务query、fragment、空/伪链接、节点位置 | 按钮能点不代表有可发现地址；不从JS文本猜URL |
| 重复导航 | 同来源-目标一条关系、全部出现位置 | 原始出现次数不是独立入链页面数 |
| 图与深度 | 指定首页/分类/业务入口的观察最短路径 | 阈值4不是排名红线；缺少源页面不证明不可达 |
| 无入链 | 资产库中没有观察到A入链的候选 | 不等于全站绝对孤立；跳转落地页需合并HTTP链判断 |
| 404/410 | 本次GET观察到的断链目标和所有观察来源 | 不证明永久删除；软404需正文/平台证据 |
| 5xx/403/429 | 服务器错误/访问受限，保留时间环境 | 不误判为永久断链，不反复冲击站点 |
| 重定向 | 实际逐跳状态、最终目标及原始来源 | 不未经内容/实体/语言等价核验就批量改成最终URL |
| 空锚文本 | 缺可用文本/alt/title候选，保留ARIA线索 | 不等于完整可访问名称失败；不机械要求所有图标链接添加可见文字 |
| nofollow | 内链资格线索 | 不等于绝对无法抓取或发现 |
| 分页 | 点击前后条目/URL、声明href、独立直达、交互专有状态 | 不因为没有rel=next/prev就判错；不同时间行情排序变化不是必然路由错误 |
| 语言 | 明确预期与目标html lang主要语言差异、交010 | 路径前缀不同不自动判错；不把声明当正文自然语言证明 |
| 参数增长 | 指定阈值下的变体族、数量与有限样例 | 不证明无限陷阱，不无限爬取确认 |

修复需由Codex补充到具体模板/组件：断链聚合所有已观察来源；重复模板可先改共享组件再抽样回归。新增入口需实际相关分类/正文及语言实体匹配，无来源资料时标待核验建议。完整边、位置、路径在CSV/JSON，不隐藏只展示3条之外的记录。

初始与稳定DOM的观察边可联合形成图，需读取每条边的representation；仅渲染出现的A可作为观察，但不是Google已发现的证据。interaction_only边排除，条件noscript单独计数；SVG链接/复杂错误HTML等边界需浏览器与006协同，不宣称此解析器等同完整浏览器HTML解析规则。

官方资料（2026-09-17复核）：
- [Google链接实践](https://developers.google.com/search/docs/crawling-indexing/links-crawlable)：A元素与可解析href、图片alt、锚文本上下文和内链发现。
- [Google分页实践](https://developers.google.com/search/docs/specialty/ecommerce/pagination-and-incremental-page-loading)：分页独立地址、顺序链接与可抓取内容，不依赖爬虫点击控件。
