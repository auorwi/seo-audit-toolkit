运行前设置 `SEO_SITE_PROFILE=/absolute/path/site.json`。使用 `seo.py init` 为目标站点创建显式配置；主机采用精确白名单，不自动扩展子域。默认使用通用网站规则；`business_profile: "bingx"` 为可选业务扩展，只有明确选择它才启用对应路由和市场参考逻辑。缺少 profile 时不进行线上采集。

默认交付本地报告或问题清单。只有用户明确要求外部发布并指定或确认目的地时，才调用相应飞书/外部工具写入；无需发布时不要求外部账户授权。所有输出、证据和状态库存放在技能目录之外，按站点隔离。示例、fixtures 和既有历史记录仅用于显式选择的离线演练，不自动导入真实报告。浏览器的通用就绪信号仅证明可见正文与有限稳定性，不证明业务实体正确；如提供身份/模板信号则保持这些更强要求。


# HTML 标签检查

只检查常见标签是否缺失、结构是否合理。报告写具体问题，一条一句，不写长篇修复方案、工具术语或 SEO 影响分析。

## 范围

支持单页、部分、全量。沿用用户已指定的清单；不明确时询问范围，不能自行缩成三个样本。

每次打开页面前，先告诉用户具体页面名称、URL 和数量。长清单提供完整可打开文件。全量指约定清单内所有页面；不能只抽样，也不擅自扩展到全站库存。清单工具见[范围与执行](references/scope-and-execution.md)。

## 检查

逐页用真实浏览器打开，读取实际渲染后的 DOM。每页保留 URL、时间和相关标签片段作为内部证据。页面打不开或仍在加载就写“未完成”，不算通过。

默认只检查：

- `title`、`meta`：是否缺少页面需要的声明，指出具体名称，如 `meta description`、`meta viewport`；不能笼统说“缺少 meta”。不把 keywords、robots、Open Graph 一概当成必填。
- `a`：真正用于页面跳转的链接是否有有效 `href`；是否用 `javascript:`、空 href 或仅点击事件代替目标地址。有真实 href 的客户端路由不算错误；按钮操作不当作页面跳转。
- 内链参数：逐页检查内部 A 链接是否携带不必要的埋点、追踪参数。按参数用途判断，不按 URL 长度判断；保留币种、语言、分页、筛选等必要业务参数，用途不明的标为待确认。
- 非 A 跳转：检查实际跳转到其他页面的卡片、文字、图标、按钮等，是否未使用带有效 `href` 的 A 标签。结合真实浏览器交互确认；展开菜单、切换选项、打开弹窗等页面内操作不算这类问题。A 内的子元素不能误判为非 A 跳转。
- `ul/ol/li`：列表容器、列表项及有序/无序用途是否正确。
- `h1–h6`：主标题、空标题和上下级关系。结合内容判断，例如同一分节从 H2 跳到 H4；返回较高层级不算顺序错误，也不机械认定每页只能有一个 H1。
- `main/nav/aside/header/footer`、`table/th/td`：按实际用途检查主内容、导航、补充内容及数据表结构；不要求每页把所有标签用齐。

到这里结束。默认不做颜色对比度、缩放、控件可访问名称、媒体、性能、索引、Schema 或全面内链审查。Nu/axe 可辅助定位，但不是必跑项，也不能把它们的整份结果直接塞进报告。工具候选需要逐条核对，只有上述范围内的真实标签问题进入最终清单。

可直接根据浏览器 DOM 整理清单；已有采集脚本仅作辅助，运行环境见[运行环境](references/runtime.md)，导入既有机器证据时再读[证据合同](references/evidence.md)。脚本生成的是初稿，发布前检查范围、去重并改成简短中文；不要把工具待审误称为已确认问题。

每页必须完成[范围与执行中的 A 标签专项检查](references/scope-and-execution.md#a-标签专项检查)。现有机器脚本的结果不代表已覆盖内链参数和非 A 跳转；未执行这两项时明确记录未检查。

## 报告

默认生成本地 Markdown 问题清单。每页只出现一次，页面名和 URL 下列未勾选的 checkbox；仅在用户明确要求发布到指定或确认的飞书目的地时，通过 `lark-doc` 写入原生 checkbox 并回读。同类重复问题合并，不为了简短漏掉不同问题。用户没有要求时不展开解决方案；只在难以理解时附一个短标签例子。

格式示例（不是任何页面的实际检查结果）：

> 币种详情页｜URL
> - [ ] 缺少 meta description。
> - [ ] 部分 A 标签使用 JavaScript 跳转，没有有效 href。
> - [ ] 正文内链携带不必要的 utm_source 追踪参数。
> - [ ] 币种卡片点击后跳转详情页，但未使用 A 标签。
> - [ ] UL 的子元素未使用 LI。
> - [ ] H2 下直接使用 H4，标题层级跳级。

无问题写“未发现标签问题”；无法确认的写“待确认”，未检查的写“未检查”。正文不展示工具统计、分类代码、SHA、日志、重复免责声明或大段验收步骤。详细证据留本地备查。

用户要求飞书发布时，才使用[飞书交付](references/feishu-delivery.md)。保留用户已有勾选，不发送消息、不修改分享权限。发布失败如实说明，不能把本地文件当作飞书交付。
